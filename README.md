# 鹿陽學習觀測

115 年度鹿陽國小五年級學力測驗的公開彙總儀表板。資料範圍只有五年級 501 班，三科各 23 筆成績，不能代表全校其他年級或班級。

## 功能

- 三科總覽：報表班平均、等級人數及百分比。
- 平均口徑切換：原報表班平均與 23 筆紀錄平均分別標示。
- 班級分析：國語文、英語文、數學能力向度，支援分類與排序。
- 匿名分布：五個答對率區間的各科人數與可讀取數據表。
- 逐題觀察：有效作答紀錄的答對率、答對與答錯人數、空白筆數。
- 響應式排版、鍵盤操作、減少動態效果設定及列印樣式。

## 資料口徑

`data/assessment.json` 僅保存彙總資料，沒有學生姓名、性別、座號、個人 PR、個別成績、跨科個人對照或個人逐題作答。

原始 Excel 與 PDF 不在此儲存庫內。來源為各科「班平均」「各校等級資料」「答對率」「作答反應」Excel，於本機彙總後匯出。

1. 報表班平均與能力向度平均直接使用「班平均」檔，不以個人紀錄覆寫。
2. 紀錄平均依 23 筆個人整體答對率重算；原始百分比已四捨五入，結果為近似值。兩種平均有差異，來源未明確註明原因，因此保留並分別標示。
3. 等級人數與「各校等級資料」核對一致，含原報表所列特殊生。等級比例由 23 人重算至小數一位。
4. 匿名分布採 0–19%、20–39%、40–59%、60–79%、80–100% 五個區間，並非等級切點。
5. 逐題百分比以非空白的 0／1 二元反應為分母。空白不視為答錯，另列筆數。
6. 未提供的學生紀錄不補造；不推定缺漏原因。

## 本機瀏覽

無外部字型、追蹤程式、CDN 或套件依賴。從專案目錄執行：

```sh
python -m http.server 4173 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:4173`。請使用 HTTP 伺服器，直接以 `file://` 開啟 HTML 會受到瀏覽器對 JSON 讀取的限制。

## GitHub Pages

部署來源為 `main` 分支根目錄，包含 `.nojekyll`。網站使用相對路徑，可部署在 repository Pages 子路徑。資料更新時以彙總檔替換 JSON，勿加入來源個人成績檔。
