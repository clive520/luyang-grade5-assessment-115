# 一起讀懂學力測驗 · 鹿陽學習觀測

115 年度鹿陽國小五年級 501 班學力測驗的公開解讀網站。三科各有 23 筆成績；沒有其他班級、年級或年度比較。

## 閱讀順序

1. **30 秒重點**：先了解整體位置、學生差異與練習起點。
2. **測驗怎麼讀**：由作答、統計、能力向度到練習確認，並解釋答對率、等級與向度。
3. **同科參考比較**：本次原報表平均與臺中市、總參與縣市的比較，差距使用「百分點」。
4. **看見學生差異**：每點 1 人的等級圖、匿名區間分布，提醒各科人數不能相加成學生總數。
5. **逐科理解**：資料結果、白話解讀與練習建議分別標示。向度可連至相關題號、題數與全班作答統計。
6. **下一步**：家長、學生與老師可各自切換行動建議；老師版提供各科等級人數。

詳細內容可展開閱讀，基本解讀直接顯示。支援手機、鍵盤操作、減少動態效果與列印目前選取的科目及身分內容。

## 資料與解讀

`data/assessment.json` 僅保存班級彙總、等級人數、區間人數、能力向度、題號對應、逐題答對人數與參考平均。沒有學生姓名、性別、座號、個人 PR、個別成績或個人答案。來源 Excel、PDF 均未加入儲存庫。

- 原報表平均直接取自各科「班平均」Excel。23 筆紀錄平均另依個人整體答對率重算，原始百分比已四捨五入；兩者有差異，來源未註明原因，故分別標示。
- 等級分類沿用來源「各校等級資料」，含原報表所列特殊生。區間分布與等級不同。
- 逐題以非空白 0／1 反應為分母，空白另列、不直接算錯。
- 參考平均及向度題號採[使用者指定的參考網站](https://clive520.github.io/lyps-assessment-115/)整理資料；三科圖表已對照原始班級向度答對率 PDF。26 個向度的題號對應已逐筆與本機原始作答反應、個人向度答對率核對一致。
- 「總參與縣市」不等於全國所有學生。不同科目難度不同，不據此比較跨科能力。差距不代表統計顯著或教學因果效果。
- 單題或少題向度需要其他題目再確認。網站中的白話說明及練習例子為建議，非官方診斷、原試題或已實施紀錄。

## 開啟與部署

靜態 HTML、CSS、JavaScript；無外部字型、CDN、追蹤程式或套件依賴。

```sh
python -m http.server 4173 --bind 127.0.0.1
```

本機開啟 `http://127.0.0.1:4173`。須以 HTTP 提供資料，直接開啟 HTML 會受到瀏覽器 JSON 存取限制。

GitHub Pages 使用 `main` 分支根目錄及 `.nojekyll`，所有資源使用相對路徑。
